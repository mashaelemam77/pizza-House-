
# 🍕 Pizza House POS System

![C#](https://img.shields.io/badge/C%23-.NET-purple?style=flat&logo=c-sharp)
![WinForms](https://img.shields.io/badge/UI-Windows%20Forms-blue)
![Status](https://img.shields.io/badge/Status-Completed-success)

A complete **Point of Sale (POS) Desktop Application** built with **C# and Windows Forms (.NET)**. The system is designed for a pizza restaurant to streamline order management, customize pizza configurations, compute billing in real-time, and print formatted digital receipts.


---


## ✨ Features

- **Menu Selection:** Select items across multiple categories (Pizza, Appetizers, Drinks) with customizable quantities.
- **Real-Time Billing:** Automatic calculations for:
  - Base Cost
  - Service Charge
  - TAX (VAT)
  - Sub Total & Grand Total
- **Receipt Generation:** Renders a clean, formatted receipt summarizing all selected items and final costs.
- **Quick Controls:** Buttons to calculate total, reset inputs, print/view receipt, and exit the system.

---

## 🛠️ Built With

* **Language:** C#
* **Framework:** .NET (Windows Forms / WinForms)
* **IDE:** Visual Studio

### 🚀 How to Run Locally

1. **Open the project:**
   * Open Visual Studio.
   * Select **Open a project or solution**.
   * Locate and open `PizzaHouse.sln` (or your `.sln` file).

2. **Run the Application:**
   * Press `F5` or click the **Start** button in Visual Studio.
