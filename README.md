# 🍕 Pizza House - Order Management System

A desktop Point-of-Sale (POS) application built with **C#** and **Windows Forms (WinForms)**. This application allows users to select pizza, appetizers, and beverages, automatically calculate costs (subtotal, service charges, tax, and total), and generate an itemized customer receipt.

---

## ✨ Features

- **Menu Selection:** Select items across multiple categories (Pizza, Appetizers, Drinks) with customizable quantities.
- **Real-Time Billing:** Automatic calculations for:
  - Base Cost
  - Service Charge
  - TAX (VAT)
  - Sub Total & Grand Total
- **Receipt Generation:** Renders a clean, formatted receipt summarizing all selected items and final costs.
- **Quick Controls:** Buttons to calculate total, reset inputs, print/view receipt, and exit the system.
